# Office Dota 2 Team Builder — Live Snake Draft

6 багийн ахлагч тус бүр өөрийн аккаунтаар өөр өөр газраас нэвтэрч, нэг самбар дээр шууд (real-time) драфт хийнэ. Нэвтрээгүй хүмүүс зөвхөн үзнэ.

## Аккаунтууд (accounts.json — заавал солиорой!)
Админ `admin` нэрээр, багийн ахлагчид `team1`–`team6` нэрээр нэвтэрнэ. Нууц үгсийг `accounts.json`-оос харна. Ахлагчийн нууц үг тус бүр 6 латин үсэгтэй, том жижиг үсэг ялгана.

Хостинг дээр `ACCOUNTS_JSON` ашигладаг бол нууц үгсийг тэнд шинэчилнэ. `TEAM6_PASSWORD` тохируулсан бол 6-р багийн нууц үгийг уг хувьсагч тодорхойлно.

“Ахлагч хадгалах” дарахад ахлагчдад Баг 1..6 дугаарыг санамсаргүйгээр (random) оноодог (Баг 1 эхэлж сонгоно). Ахлагчийн нэрийн хажууд “Баг N” шошго гарна — тэр дугаартай аккаунтыг нь өгнө. Дахин random хийх бол нэг ахлагчийг болиулаад буцааж сонгоод дахин хадгална.

## Ажиллуулах
```
npm install
npm start          # http://localhost:3000
```
Орчны хувьсагч: `PORT`, `SECRET` (токен гарын үсэг — заавал солих), `DATA_FILE`, `ACCOUNTS_JSON` (accounts.json-ийн оронд JSON string).

## Интернэтэд гаргах (өөр газраас нэвтрэх)
Render.com / Railway / Fly.io эсвэл өөрийн VPS дээр Node web service болгон байршуулна:
- Build: `npm install` · Start: `npm start`
- WebSocket дэмждэг байх (дээрх бүгд дэмждэг).
- Тоглогч нэмэх зэрэг өөрчлөлтийг сервер амжилттай гэж хариулахаас өмнө `DATA_FILE` дахь JSON-д хадгална. Deploy болон дахин асаалтын дараа бүртгэлээ хадгалахын тулд хостингийн persistent disk холбож, `DATA_FILE`-г тухайн диск дээрх файл руу заана.
- Анх асаахад `draft-result.json` дахь тоглогчдын бүртгэлээр 6 багийн шинэ драфтыг бэлдэнэ. Өмнөх драфтын үр дүн уг файлд архив хэвээр байна.

## Драфтын урсгал
1. Админ нэвтэрч тоглогчдоо шалгана (өмнөх драфтын 25 тоглогч урьдчилан орсон). 6 багийг тус бүр 5 хүнтэй бүрдүүлэхийн тулд дор хаяж 5 тоглогч нэмнэ.
2. Титэм дээр дарж 6 ахлагчийг сонгоно → “Ахлагч хадгалах”.
3. “Драфт эхлүүлэх” → snake дараалал 1→2→3→4→5→6→6→5→4→3→2→1…
4. Ахлагч зөвхөн өөрийн ээлжинд “Сонгох” дарж чадна. Админ хэрэгтэй бол хэний ч өмнөөс сонгох, “Буцаах” хийх боломжтой.
