# Office Dota 2 Team Builder — Live Snake Draft

5 багийн ахлагч тус бүр өөрийн аккаунтаар өөр өөр газраас нэвтэрч, нэг самбар дээр шууд (real-time) драфт хийнэ. Нэвтрээгүй хүмүүс зөвхөн үзнэ.

## Аккаунтууд (accounts.json — заавал солиорой!)
| Нэр   | Нууц үг     | Эрх |
|-------|-------------|-----|
| admin | admin2026   | Тоглогч нэмэх/засах, ахлагч сонгох, драфт эхлүүлэх, буцаах |
| team1 | baga1-2026  | Баг 1-ийн ахлагч |
| team2 | baga2-2026  | Баг 2-ийн ахлагч |
| team3 | baga3-2026  | Баг 3-ийн ахлагч |
| team4 | baga4-2026  | Баг 4-ийн ахлагч |
| team5 | baga5-2026  | Баг 5-ийн ахлагч |

“Ахлагч хадгалах” дарахад ахлагчдад Баг 1..5 дугаарыг санамсаргүйгээр (random) оноодог (Баг 1 эхэлж сонгоно). Ахлагчийн нэрийн хажууд “Баг N” шошго гарна — тэр дугаартай аккаунтыг нь өгнө. Дахин random хийх бол нэг ахлагчийг болиулаад буцааж сонгоод дахин хадгална.

## Ажиллуулах
```
npm install
npm start          # http://localhost:3000
```
Орчны хувьсагч: `PORT`, `SECRET` (токен гарын үсэг — заавал солих), `DATA_FILE`, `ACCOUNTS_JSON` (accounts.json-ийн оронд JSON string).

## Интернэтэд гаргах (өөр газраас нэвтрэх)
Render.com / Railway / Fly.io эсвэл өөрийн VPS дээр Node web service болгон байршуулна:
- Build: `npm install` · Start: `npm start`
- WebSocket дэмждэг байх (дээрх бүгд дэмждэг).
- Төлөв `data.json`-д хадгалагдана. Үнэгүй хостинг дахин асахад файл устаж магадгүй — persistent disk холбох эсвэл `DATA_FILE`-г disk руу заана.

## Драфтын урсгал
1. Админ нэвтэрч тоглогчдоо шалгана (23 тоглогч урьдчилан орсон).
2. 4/5 баг сонгоод титэм дээр дарж ахлагчдыг сонгоно → “Ахлагч хадгалах”.
3. “Драфт эхлүүлэх” → snake дараалал 1→2→3→4→5→5→4→3→2→1…
4. Ахлагч зөвхөн өөрийн ээлжинд “Сонгох” дарж чадна. Админ хэрэгтэй бол хэний ч өмнөөс сонгох, “Буцаах” хийх боломжтой.
